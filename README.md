# Stealth Overhaul

Stealth Overhaul is a Project Zomboid Build 42 mod in development. It will replace
random zombie visual detection with deterministic awareness, then communicate that
state through client-side awareness indicators and obstacle-aware vision cones.

The gameplay component will use ZombieBuddy to patch zombie spotting. See
[`docs/mod.md`](docs/mod.md) for the design, configuration surface, multiplayer model,
and implementation milestones.
